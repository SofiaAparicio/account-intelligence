# Account Intelligence

A small app that helps an Account Executive answer two questions at the start
of the day: **which accounts should I focus on**, and **what should I know
before my next meeting**.

> Status: scaffold + EDA. Scoring, insight and UI layers follow.

## What it does

- Ranks ~1000 accounts by a transparent risk score and opportunity score,
  each with reason codes.
- Generates an AI meeting-prep brief for any account, grounded only in the
  account's data.
- Streamlit UI with two views: *Today's focus* and *Meeting brief*.

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # add one free LLM API key
streamlit run app.py
```
